## Recommended Actions

2. Decouple Rule 10's existence/kind/ancestor/overlap checks from `max_rounds > 0` so they run whenever `heal.targets` is non-empty, keeping only the round-based gating for the parts of the rule that depend on it.

4. Have `GitWorkspace.restore()` report checked-out vs. discarded paths so `roles.py:697` can log accurate per-path `status` values.
5. Swap doctor's probe file-check order to `("result.json", "result.txt")` for consistency with §8.3 and the executors.
6. Update the `__init__.py` docstring's authority list to include `docs/spec/AMENDMENTS-r5.md`.
